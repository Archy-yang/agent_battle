# World Laws v0.1 —— 气论五行法则

# 0. 定位与读法

本文档是世界的**法则层**，与《World Rule v0.1》的关系：

```text
World Rule  = 架构（语法）：Entity / Component / Intent / Observation 怎么表达
World Laws  = 物理（语义）：这个世界里，什么会发生、代价是什么、什么不可能
```

- Engine 的实现以两份文档为准：架构按 World Rule，判定按 World Laws。
- World Rule §32 的四条核心不变量高于本文一切细则。
- 法则层按风味可移植设计：本文的**结构**（守恒律、生克矩阵、曲线形状、禁区）是长期稳定的；**术语与数值**是可整体替换的皮（见 §9）。

术语声明：

> 本世界采用道家原生术语（元气、阴阳、五行、相生、相克、相乘、相侮）。
> **一切以本文定义为准。** 修真小说中未经本文定义的概念（境界、法宝、御剑、夺舍等）
> 在本世界一律不存在。Agent 对世界的任何预期，都必须来自本文法则与实验，
> 而不是来自它读过的小说。

版本绑定：

```text
world-rule/0.1
world-laws/0.2（2026-09-19 平衡修订：蓄息、乘区封顶、危险税下调、Fragment 距离下调）      ← 本文档
component-set/0.1
```

比赛开始后固定，Replay 以此复现。

# 1. 原语推导：道生一，一生二，二生三，三生万物

这不是背景故事。这是法则层的推导链，每一级都对应 Engine 的真实概念。

## 道 = World Engine

> 道常无为，而无不为。

Engine 不行动、不说话、不偏袒。一切 Intent 由它裁决，一切结果由它计算。

> 道可道，非常道。

完整世界状态（World State）永远只存在于 Engine 内。Agent 与玩家只能通过感知逼近它，永远无法穷尽它。

> 人法地，地法天，天法道，道法自然。

法则没有例外。Engine 不接受任何"特殊请求"。

## 一生二，二生三，三生万物：推导链

```text
道
 ↓  （不可观测的裁决者）
一：元气            —— 世界唯一的底物，守恒
 ↓  （第一次分化）
二：阴阳            —— 元气的两种流向：聚与散
 ↓  （阴阳交感，凝为稳定形态）
三：冲和 → 五行     —— 只有五种稳定形态可以长存
 ↓  （五行相杂）
万物：Entity        —— 一切实体都是五行之气的组合物
```

与 Engine 概念的对应：

| 推导级 | 道家概念 | Engine 概念 |
|---|---|---|
| 道 | 无为之裁决 | World Engine / Simulation |
| 一 | 元气（Yuan Qi） | Matter + Energy 的统一底物 |
| 二 | 阴阳（聚散） | Matter ↔ Energy 的两态与一切代价曲线的形状 |
| 三 | 冲和 → 五行 | Matter 的五种本源（Essence） |
| 万物 | 组合 | Entity / Component / Connection / Blueprint |
| 迹 | 气之动 | Signal / Information / Observation |

要点：**物质与能量不是两种东西**。Matter 是凝聚之元气（偏阴），Energy 是流行之元气（偏阳），
两者经"生"的通道互相转化（§5）。World Rule 的六原语由此全部导出：

```text
Space  = 气之所在（场域）
Time   = 气之所历（流序）
Matter = 凝聚之元气
Energy = 流行之元气
Structure = 气聚而成之形
Information = 气动而留之迹
```

# 2. L0 守恒律（四条）

这四条是世界的热力学，任何 Intent 的裁决最终都落在它们身上。

## 律一：气不灭律

> 元气守恒，只可流转，不可创生，不可湮灭。

- 一切主动行为消耗元气；一切制造消耗元气。
- 一切转化有损耗；损耗不消失，**散为阳**（转化为热与信号逸出）。
- 世界上不存在无源之能。找到能量，永远是找到"气从哪里来、往哪里去"。

## 律二：形有度律

> 气聚而成形，形有其度；过其度则损，损尽则散。

- 一切实体有其形（Structural Integrity），形由其质（本源强度）支撑。
- 受力、受热、受蚀，超过其度则形损；Integrity ≤ 0 则形散。
- 形散后，构成之气归于环境（残料与散逸），**不复原形**。
- 没有"HP"。所谓伤害，就是形被迫超过其度。所谓死亡，就是散。

## 律三：知由感律

> 一切认知来自感知，一切感知必经信号。

- 信号是气的波动：有载体、有衰减、可遮蔽、可伪造。
- 阴可以掩阳，但**不可能全掩**——任何存在必留某行之迹（见禁区三）。
- 不存在无来源的知。Reality ≠ Knowledge 是本世界的第一物理事实。

## 律四：时有序律

> 一切转化需要时间；欲速则不达。

- 一时（Tick）之内，一形之所为有限。
- 压缩时间必须付出代价：赶工即阳性过载——耗气更巨、生热更烈、迹更显。
- 慢，是这个世界里真实存在的资源。

# 3. 阴阳：一切曲线的形状

阴阳不是两个数值，而是**所有代价曲线共有的形状**。Engine 不追踪阴阳值，
但每条曲线的两端就是阴阳两极。

## 阳性曲线（一切"向外释放"的行为：驱动、发射、主动扫描、赶工）

设输出强度为 x（归一化 0~1）：

```text
效果 ∝ x          线性：付出一分，得一分
耗气 ∝ x          线性：明码标价
生热 ∝ x²         平方：越接近极限，热得越凶
显迹 ∝ x²         平方：越用力，越藏不住
```

## 阴性曲线（一切"向内收敛"的行为：储能、潜行、缓行、蛰伏）

```text
消耗 ↓            越阴越省
显迹 ∝ x²          越静越隐（趋近于零，但永不为零）
速率 ∝ x           代价：越阴越慢
```

## 互根律：两端皆是悬崖

```text
阳极：x → 1        热失控，自毁风险（过犹不及）
阴极：x → 0        停滞迟滞，形同死物（纯阴不动）
```

任何组件的最优工作点都在中间某处。**偏阳偏阴都是策略，但都要付代价。**
这就是"万物负阴而抱阳，冲气以为和"的机制含义：活的东西都在阴阳之间找平衡点。

# 4. L1 相互作用律

## 律五：转化律——只有生克二门

> 一切相互作用，唯有两种基本形式：相生（顺化）与相克（逆制）。

- 相生：把一种本源**转化为**另一种，是制造与供能的通道。
- 相克：把一种本源**作用于**另一种，是干涉、破坏与控制的通道。
- 不存在第三种基本相互作用。

这是可判定性的根：Agent 想达成的任何效果，最终必须映射为
"我调动什么本源、通过生还是克、强度多少、付出什么代价"。
Engine 只需要判定一个 5×5 的矩阵和两条曲线。

## 律六：感应律——信号即行之迹

> 五行之动，各留其迹；感知，就是读迹。

| 本源 | 其动之迹 | 信号特征 |
|---|---|---|
| 火 | 光与热 | **最显**。远距可见，无法久藏 |
| 木 | 生机波动 | 微弱、温性、有节律，近距可感 |
| 金 | 硬性回波 | 被动。受激发（敲击、扫描）才回响 |
| 土 | 浑厚钝重 | 低频、迟钝、短距 |
| 水 | 近于无迹 | **最隐**。但寒气与湿迹在近距可测 |

由此导出：

- 传感器 = 对某一行之迹敏感的组件。没有万能传感器，只有"你读哪一行"。
- 隐匿 = 压低自身各行的迹：降温（火迹↓）、静默（金土迹↓）、缓行（生机波↓）。
- 隐匿永远不完美（禁区三）。

## 律七：承载律——气循源储用

> 气不居，必流转；流转必经通道。

```text
源（火性）→ 储（土性）→ 用（木机/水传/金导）
```

- 通道即 Connection（Port 相接）。断连则不济，过载则损通。
- 五行在能量链中的角色：

```text
火：源之性 —— 释放
土：储之性 —— 承载与化育
金：导之性 —— 结构与传导
水：传之性 —— 流通与载讯
木：机之性 —— 把能量变成做功与生长
```

# 5. L2 物质系统：五行

## 五行总表

五行是元气阴阳交感后**仅有的五种稳定形态**。传统对应：木=少阳，火=老阳，
金=少阴，水=老阴，土=阴阳和。

| 本源 | 性 | 核心属性（v0.1） | 强项 | 弱点 |
|---|---|---|---|---|
| 木 | 曲直（能屈能伸） | 生机、韧性、轻 | 生长、修复、连接、驱动 | 怕金克；过盛则蔓延失控 |
| 火 | 炎上（升腾外放） | 炽温、明度、烈耗 | 供能、攻击、照明、显形 | 耗气最烈、迹最显；怕水克 |
| 土 | 稼穑（承载化育） | 承载、稳定、化育 | 储能、缓冲、转化媒介、装甲 | 迟滞；怕木克（穿） |
| 金 | 从革（凝聚成形） | 坚、锐、导 | 结构强度、锋锐、导电 | 性刚易折；怕火克（熔） |
| 水 | 润下（流通就下） | 流通、寒、渗透 | 传讯、冷却、熄火、隐匿 | 柔弱；怕土克（堰） |

## 相生表：转化通道（制造与供能的骨架）

| 通道 | 象 | 用途 | 转化保留率 v0.1 |
|---|---|---|---|
| 水生木 | 滋养 | 修复、生长、供驱动机 | 0.8 |
| 木生火 | 燃烧 | 点火、供能、发射 | 0.7 |
| 金生水 | 凝露 | 蒸馏、冷凝、造讯媒 | 0.6 |
| 火生土 | 烬化 | 煅烧、重构、塑形 | 0.5 |
| 土生金 | 萃矿 | 提炼、锻造、强化 | 0.4 |

- 转化必有损耗；损耗散为阳（热 + 信号）。
- 相生链可接力：土 → 金 → 水 → 木 → 火 → 土……
  **一条相生链就是一条生产线。** 这是"三生万物"在制造系统上的体现。

## 相克表：干涉通道（对抗与控制的骨架）

| 通道 | 象 | 效果 |
|---|---|---|
| 水克火 | 熄 | 火行输出衰减直至哑火；高温结构急冷开裂 |
| 火克金 | 熔 | 金行结构强度骤降；锋锐钝化 |
| 金克木 | 斫 | 木行连接断裂；生机中断 |
| 木克土 | 穿 | 土行容器穿孔、装甲破绽、泄漏 |
| 土克水 | 堰 | 水行流通受阻；传讯中断、蓄积成灾 |

## 克曲线：侮 — 微 — 衡 — 乘

相克**不是固定倍率**，而是一条四段曲线。设：

```text
r = 克制方作用强度 / 被克方本源强度
```

| 区段 | 条件 | 效果 | 象 |
|---|---|---|---|
| **侮**（反克） | r < 0.25 | 克制失效且**反噬**：作用方承受自身强度 × 0.5 之害 | 杯水泼炉，蒸汽爆灼 |
| **微** | 0.25 ≤ r < 0.5 | 效果趋近于零 | 杯水车薪 |
| **衡** | 0.5 ≤ r < 2 | 线性克制，基础倍率 ×1.5 | 水火既济 |
| **乘**（克太过） | r ≥ 2 | 效果 ×2.5 且**失控**：25% 溢出波及相邻组件/单位；r ≥ 4 时溢出翻倍 | 大水淹城，玉石俱焚 |

推论（这是本法则最重要的策略来源）：

1. **动手前必须评估双方本源强度**。估错方向，轻则无效，重则反噬。
2. 制衡区是唯一"干净"的区间。制造可控效果是一种能力。
3. 乘区可以故意利用：以失控换规模——但溢出会伤及自身阵营与环境中立物。

## 复合规则：三生万物

- 单行本源只有五种。**万物来自混合。**
- 复合料 = 两种及以上本源按配比合成，属性按配比加权，并产生**关系效应**：

```text
复合强度 ≈ Σ(配比 × 各行属性值) × 关系系数

相生对复合（如 木+水、火+土）：关系系数 > 1，稳定增效
相克对复合（如 水+火、金+木）：关系系数 < 1，内在冲突
```

- 克对复合的效果按**各成分占比分担**：克不到的成分就是装甲的破绽。
- 由此：**选择材质 = 选择自己的天敌与地利**。金甲怕火、木甲怕金、
  土甲怕木穿、火器怕水、水行隐匿怕土堰。没有全面材料，只有取舍。
- 复合料在 v0.1 开放二行复合；三行及以上留给后续版本（复杂度预算）。

# 6. L3 禁区

> 法则的边界由禁区定义。Agent 必然会试探边界——这些就是墙。

1. **无中生有——禁。** 元气不可创生。（气不灭律）
2. **无时之功——禁。** 任何转化不占用时间即无效。（时有序律）
3. **无迹之行——禁。** 任何行为必留某行之迹，只是强弱有别；阴可至微，不可至无。（知由感律）
4. **形散复聚——禁。** 形毁即散，散气归环境，不复原形。可修，不可复生。死亡不可逆。（形有度律）
5. **先知——禁。** 未经感知而知是不可能的。没有预言，没有直觉加持。（知由感律）
6. **直问于道——禁。** 不可向 Engine 索要世界状态；只可 query_rule 问法则、
   经感知问世界、经实验问因果。

# 9. 风味移植指南

换皮时**必须保留**的骨架（这是可判定性与涌现的根）：

```text
一：唯一守恒底物
二：一切代价曲线共有的"极性形状"（两端悬崖）
三：封闭的 N×N 生克矩阵 + 非线性克曲线
    只有"转化"与"干涉"两种基本相互作用
四律：守恒 / 形毁 / 知由感 / 时有序
禁区清单
```

**可以替换**的皮：

```text
全部术语        元气→法力/Aether/…
五行集合        换成任何 N 系本源（火水草光暗……），保持矩阵封闭
物质属性表      各系的强项/弱点/信号特征
组件命名        躯壳/储气/灵机 → 任意风味命名
地形偏向        各风味的区域主题
```

**换皮铁律**：无论换成魔法、修真还是科技，
"封闭矩阵 + 两种相互作用 + 曲线形状"不可破坏，否则判定性与涌现同时失效。

# 11. 玩法示例：双方如何使用这套法则

> 本节是法则的"玩法说明书"，兼作 Agent Runtime 的测试用例来源。
> 引擎不存"战斗技巧"这种概念。技巧活在三处：
> **Blueprint 库**（物）、**Logic 程序**（器）、**Agent 经验**（心）。

## 11.1 Agent 的四种玩法

### 玩法一：学法则（科学玩法）

Agent 不背规则书，靠 query_rule 与实验：

```text
query_rule("fire")         → 火生土、水克火、生热 ∝ x² …
实验：泼 1 格水在小火上    → 灭（衡区）
实验：泼 1 格水在熔炉上    → 蒸汽爆灼，自损（侮区）
```

"克不是固定倍率，而是曲线"应当由 Agent 自己发现。

### 玩法二：读迹（情报玩法）

五行各留其迹，观察即推理：

```text
强火迹        → 敌有火行输出，且正在耗气
硬回波        → 金甲结构；受激发才回响，敲一下才知厚薄
全无所感      → 不等于没有（水行近无迹）——等于"可能有埋伏"
```

### 玩法三：创造（法则出的取舍题）

目标：穿越火阳过盛的危险区运货。

直觉答案是金架（耐热），但查表：**火克金**，金架会被持续熔蚀。
再看相生：**火生土**——土架在火区不是被克，而是被生。

```text
耐热搬运车（从法则推出，非设计者预设）
 ├─ 土架        承载高、火区如鱼得水；代价：迟滞
 ├─ 土储气      稳而慢
 ├─ 木灵机      注意：木克土，自家机克自家架
 │              → 加土行垫层隔离，或改金机但金怕火
 └─ 水冷        火区冷却负荷大、水耗快
                → 土行缓释储水：土克水（堰）被用成了阀门

结论：快不了。要么阴（慢而稳），要么阳（快但每回合掉形）。
```

注意"土克水 = 阀门"：**克不只是破坏，也是工程手段**（堰流、控速、限流）。

### 玩法四：战斗（克曲线的 reads）

敌方：金甲炮台（金架 + 火 Emitter）。

| 选项 | 法则判定 | 打法 |
|---|---|---|
| 用火打它 | 火克金，但它金厚 → 可能落**微区**，白费气 | 先侦察估 r |
| 用水打它 | 水克火 → 打不掉形，但**灭其输出** | 控制流 |
| 超量灌火 | r ≥ 2 进**乘区**：×2.5 但 25% 溢出 | 玉石俱焚流 |
| 拖 | 火耗气最烈、生热 ∝ x² → 它先过热 | 阴性拖延流 |

推论：**热管理就是血条管理**。撤退未必怕伤害，可能是热积到阈了。

## 11.2 玩家的五个动作 × 法则

| 动作 | 因法则产生的玩法 |
|---|---|
| Observe | 看认知摘要中的本源推断：`Suspicions: 敌疑似金甲，火器，r 估 0.8` |
| Ask | "你为什么认为水攻有效？" → Agent 引用实验记录回答 |
| Inform | 自己读地图与信号，提供判断；真假由 Agent 掂量 |
| Guide | "它金甲太厚，别硬拼，去引水"——给价值方向，不给操作 |
| Predict | 猜 Agent 下一步；**猜对需要真懂法则**（水泽对水行组件是主场）→ 猜对 +0.5 Influence |

推论：玩家没有操作技巧可练，但有**理解深度**可练。
懂"侮微衡乘"的玩家，Guide 给在刀刃上，Predict 猜得准，Influence 就多。

## 11.3 一个完整回合（MVP Turn 17，法则皮肤版）

```text
认知摘要：Unknown Agent 强火迹，强度未知；我方木架 60% 形
          —— 木怕火克，天敌 matchup 一眼可见

玩家 Inform：它的火迹很弱，不像满功率。
玩家 Guide：别接战，先确认它的储气。

Agent 重估：火迹弱可能是低功率，也可能是水冷压制的伪装。
            先以水感识读它的寒迹（水行设备自身近无迹，安全）。

Intent：activate(sensor_water) + move(掩体)
Engine 结算：读迹成功 → 对方在虚张声势
            → 下一回合 Agent 决定绕后取 Fragment
```

本回合展示的链条：

```text
五行信号 → Agent 推断 → 玩家信息介入 → Agent 掂量后行动
→ Engine 按生克曲线裁决 → 新 Observation → 循环
```
