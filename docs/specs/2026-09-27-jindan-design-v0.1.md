## 1. 金丹是什么

一句话（世界语言）：

> 筑基之后，自主环流长年行转，滤杂存精。周身诸穴各按亲和「留与散」，
> 而回流汇点、保留之最、炼化之锚三者同归一处——于是有一处地方，
> 精纯之气经年沉淀、聚拢成实，纵然止念安养、不纳不推，它也安然不散。
> 这一处沉实的凝聚，修真文明称之为「金丹」。

因果链（与筑基同构：先有结构，后有命名）：

```text
自主环流长期运转（筑基已立）
        ↓
筛选经济学持续作用：亲和者留、驳杂者散（修订包 D3）
        ↓
精纯之气沿环流归元，日复一日汇于保留度最高之处
        ↓
汇点储气的构成收敛于「身与轨之合」（炼化导出量升入高位并企稳）
        ↓
止念安养时凝聚不散（自持）、波动不崩（丹稳）、与环相济不竭（相济）
        ↓
引擎观察到稳定的凝实结构，判据满足
        ↓
上层文明称之为「金丹」；结构之相进入凝实核心
```

境界序列中的位置：

```text
散气序列（炼气） → 自主循环（筑基） → 凝实核心（金丹） → [待定义]
```

「凝实核心」沿用境界文档 §2.2 的引擎侧结构名；「金丹／结丹」只存在于
文明命名与叙事层（§5.3），底层零专名。

## 2. 为什么不是「丹田气多」

境界文档 §5.2 的告诫在现役物理下更加锋利：**大量分散灵气不是凝聚结构**。
三道鉴别面，全部由既有物理自然承担，无需新增任何专门机制：

**其一，囤气守不住。** 自然吐纳的被动基线按「只维持、不充盈」标定——
没有环流的经济学，气只是躺着；而驳杂之气按诸穴亲和被日复一日地
「留与散」，构成不收敛的库存只会缓慢漏走。装满则吸不进的烧蚀闭环
（修订包 D6，标定已证）同时封死了「纯靠灌」的通路：想纳新气，
必须行环腾挪；行环本身就在筛选。

**其二，三股经济汇于一处，才有凝聚。**
回流之汇——环末归元，多穴调和后的气沿环流回到这里；
保留之最——「留与散」的差分经年累月偏向保留度最高的穴位；
炼化之锚——归一化区间在此处被画像钉死，炼化的收敛吸引子可达
（锚定的来由与工程锚点见附录）。三者在现役画像下同归于驱动显著
主导之穴（核点）。缺任何一股，凝聚都不成立：只有汇点而无筛选，
那是仓库；只有筛选而无汇点，精纯之气散在途中。

**其三，密度的新形态是「纯」，不是「多」。** 旧稿以「量／容积」论密度；
新物理里没有容积，凝聚体现在构成上——**驳杂即散（构成上的散），
精纯即凝**。旧稿的 density 与 coherence 两个语义，在此分别落为
凝实（储量与容量之比）与精纯（构成收敛于身轨之合），外加
波动受控（丹稳）与止念不散（自持），共成五量（§3）。

## 3. 相变判据（金丹五量）

延续筑基五量的风格：引擎可检测、次数不进判据、评估器只读、
全部由既有导出量重算、不落任何新存储字段。

### 3.1 前置条件

```text
自主循环已立（筑基成立）
存在核点（驱动容量显著主导判据；参数化结构判据，无专名）
```

### 3.2 五量定义

观察窗与滚动口径同筑基判读的既有形态；以下量逐拍由世界真值重算。

**一、精纯（丹之纯）**

```text
核点储气的炼化度（导出量，D2 口径，核点锚定区间）
  候选 ≥ 0.70    成立 ≥ 0.80    [v0.1 参数·调参起点]
```

凝聚的本质是构成的收敛。炼化度是既有导出量——任何时刻可从气的
构成与身体状态重算，受伤与适应变化即重算（D2 相对性原样保留：
同一炉丹，在别身未必是丹）。

> 阈值注记：炼化存在稳态吸引子（标定遗留项 P3：双重收敛限速未达、
> 吸引子取值待重标）。**精纯阈值必须低于吸引子且为画像差异留出空间**，
> 金丹标定时与炼化时标标定联动——这是本量唯一的外部依赖。

**二、凝实（丹之盈）**

```text
核点负载比（储量 / 容量）持续达带
  候选 ≥ 0.50    成立 ≥ 0.60    [v0.1 参数·调参起点]
```

密度语义的承载者：同标度下的储量与容量之比。分散在诸穴的气不进
此量，总量多而汇点不满亦不达。不设上限——过满由规则平衡与丹稳
约束管辖（过满则承压，承压则失稳，物理自限）。

**三、自持（丹之固）**

```text
安养窗（全无意识驱动、无主动纳气的连续拍段，窗长 30 拍量级
[v0.1 参数]，同松手观察窗量级）内：

留存比 = 窗末核点储量 / 窗初核点储量
  候选 ≥ 0.85    成立 ≥ 0.90    [v0.1 参数·调参起点]

卫兵：窗内自环境的净纳入（自然吐纳基线）须低于留存量验定小份额
（0.05 量级 [v0.1 参数]），否则该窗不作数。
```

「停止输入后仍能保持」的度量。安养借修行节律自然发生（休整、
入定、行环间隙），与松手测量同形——评估器不注入、不暂停世界、
不构造测试态。

> 卫兵的存在理由：自然吐纳「只维持不充盈」的标定口径是本量成立的
> 物理前提。若标定发现被动基线足以凭空养核，则「凝聚」沦为囤积，
> 本稿作废重设计——此为标定命题 Q2（§7）。

**四、丹稳（丹之定）**

```text
核点稳定度下限：候选 ≥ 0.80    成立 ≥ 0.85   [v0.1 参数·调参起点]
窗内核点储量／构成／稳定序列的归一化波动 ≤ 阈值
（复用既有失稳计量机械，施于核点序列）     [v0.1 参数·调参起点]
```

「内部波动不快速崩解」。高凝而振荡非丹——与「高自持低动态稳定
不算筑基」同一法理。

**五、相济（丹与环）**

```text
窗内同时满足：
  环流量闭合 ≥ 0.85（回流/初发流，复用既有闭合分层口径）
  周身规则平衡 ≥ 0.85（复用既有量）
  核点储量漂移 |Δ|/量 ≤ 0.05 量级        [v0.1 参数·调参起点]
```

「与基础环流保持稳定交换」（境界文档 §5.2 末条）：丹不是环外孤物，
也不是吸竭周天的窟窿——不耗干、不疯长、吞吐与环流相续。

### 3.3 触碰与成立

```text
前置满足 且 五量候选条件连续 30 拍 → 触碰金丹门槛（一次性叙事事件）
已触碰 且 五量成立条件连续 100 拍 → 丹成（结构之相进入凝实核心）
```

持续性数字全部是 [v0.1 参数·调参起点]。**持续性是验真、不是门槛**：
它只证明判据不是瞬时碰巧，不是修炼次数、不是进度条——此为固定原则，
与筑基同一法理。

### 3.4 判定纪律（固定原则）

1. 次数不进判据；行环多少拍只通过身体真实状态（构成、储量、稳定、
   耦合）间接影响五量。
2. 判读只观察：不注入驱动、不补气、不稳结构、不注册任何东西。
3. 感知与知识侧零数字：五量真值永不进入观察（§5）。
4. 判据全部由既有导出量重算，不落新存储字段；同状态重算一致。
5. 判定口径独立记版本（jindan-metrics-v1 形态，随筑基判定口径之先例）；
   底层重演语义不动、规则版本不动。

### 3.5 反散

结构之相描述「当前存在哪种稳定结构」——结构散了，相就退回。
丹成之后若五量持续失守（连续失守拍数阈值 [v0.1 参数]），凝实核心
不再成立。散丹不是事件系统、不是惩罚规则：损伤、走火、环境断供
使精纯下降、留存破带，是既有物理的直接结果；感知侧相应表现为
渐进的「丹意消解」（§5），不给专门机制。

## 4. 策略选择面

金丹的策略含义不来自选择面板，而来自物理画像的代价结构。
玩家与分身选的是**轨道与节律**；身成什么丹，是筛选经济学的沉淀。

### 4.1 结于何处——判据落在穴上，不由点选

判据定义在「满足五量之穴」上，引擎不预定凝聚处。今日画像下驱动
显著主导者唯一，三股经济（汇、留、锚）同归其上，凝聚自然落于
该处——**「结于何处」今日表现为「养哪条环」的下游结果**（4.2）。

当身体画像扩展到允许多个显著节点（三丹田／多枢纽方向，修订包 B6，
[待定义]），各行之环各成其汇，结于何处才成为真正的选择：
高容量低通量之处宜藏不宜行（聚得快、吞吐慢）；高通量低保留之处
宜行不宜藏（来得快、漏得也快，须以更高精纯兜底）。这些代价收益
全部从画像参数自然长出，无需新原语、无需新判据——判据本来就是
逐穴重算的。本稿只留此钩，画像落地不在本期（§8）。

### 4.2 以何轨道养丹——轨道定丹性

炼化收敛的目标向量是「身体 × 轨道」的合成（修订包 D2 的固定原则：
走哪条周天轨道，决定炼成什么气）。丹之品性由此而来：

- **构成之性**：轨道所经诸穴的亲和加权，决定丹之五行偏向。
  轨道不同、构成系统不同——此命题在千级扫描中已证（轨道→构成
  分离，标定 P2）。所谓「丹之品第」，首先是构成的品第。
- **火候之源**：轨道决定热的积累轨迹（路径评估，C1：同集合不同
  顺序结果不同）。过反应炉多转之轨，交互充分而承压亦重（中庭
  瓶颈，标定 P6）；简捷之轨，行得快而构成偏窄。快与纯、广与险，
  是轨道本身的权衡，不需要「丹药品质」之类的专门规则。
- **今日拓扑下的现实**：当前身体上闭合环流唯主环一线；轨道之别
  体现为行环之法——力度、驻留、过炉转数、纳气腾挪的配比与节律
  （协议层的真实选择面）。拓扑分岔随多穴／多枢纽扩展自然打开
  （B5/B6 方向），判据面无需改动。

### 4.3 火候与节律——养丹的三组权衡

**其一，推与安。** 凝聚期猛推不加速任何东西：教门饱和，学习不因
暴力而快（标定已证）；过驱却生热生应变，直取丹稳。温和持久，
是唯一的快路——「火候」由既有驱动代价分层承担，无新规则。

**其二，动与栖。** 自持只在安养中被见证：从不安养者，判据无从
满足。安养不是死时间，而是凝聚的验证场——修行须有栖止，这是
节律策略。筑基之后功法升格为守卫（既有语义：监控、异常升级），
安养与巡行的安排正是守卫之职的分身侧表达。

**其三，纳与炼。** 想纳新气必须行环腾挪（烧蚀闭环）；行环就在
烧杂。库存的「多」与气的「纯」长期相争，均衡点因画像与环境而异——
没有普遍最优的纳炼配比（千级扫描结论：路线无唯一全局最优）。

### 4.4 丹之利——利即物理本身

依设计宪法 §16（连续结果，不做离散奖励），丹成不给任何「加成」字段。
所「得」是结构变化本身的后果：

- **高位炼化的乘子全带生效**：抗逸散（库存保值）、稳定恢复加成、
  转化增效、控制误差收窄、抗流量冲击——核点一带的行环质量整体
  抬升（修订包 D4 诸乘子，炼化导出量的既有后果）。
- **可调用的精纯储备**：驱动做功取自真实储能——储备厚则驱得久、
  外推调度有底气、过驱有余裕（做功扣真实能源的既有物理）。
- **长存与缓冲**：环境灵气断续起伏时，凝实之库是环流的底气——
  绝灵之地多撑一时，丰灵之境聚合有余（长期维持条件的储备面）。
- **丹养环、环养丹**：相济判据保证的是可持续的吞吐关系，而非
  单向的汲取——丹不是终点奖励，是环流经济学的沉淀形态。

更高层的用途（斗法、丹药、外物的精纯气源等）不在本稿范围（§8），
但上述四条是它们未来复用的物理接口。

## 5. 感知与叙事

### 5.1 感知映射（确定性，不调用任何理解能力）

全部经由既有感知流水线：真值 → 导出信号 → 趋势/时长 → 分档与滞回 →
感知令牌 → 确定性模板。玩家与分身同一信息边界，零数字、零机器词。

| 真值机（核点一带） | 感知词（阶段） |
|---|---|
| 炼化度升、趋势向上 | 丹田气息日渐沉静，散乱之感渐消 |
| 炼化度高位企稳 | 气息凝然一团，安处不动 |
| 凝实入带、趋势平稳 | 沉坠充实，触之俨然有物 |
| 安养窗内留存高 | 不运功时它亦不散，如渊之停水 |
| 安养窗内留存不足 | 稍一放置，便觉那点凝意松散了几分 |
| 核点热负荷抬升 | 丹处灼热（灼痛分型，既有痛感词承担） |
| 核点序列波动过大 | 丹珠摇曳，凝意不稳 |
| 五量候选持续达成 | 凝意历久自持，隐隐欲圆——似有结丹之兆 |
| 五量成立持续达成 | 气结如丹，安处其中，自行吐纳，与周天相续不辍——丹成 |
| 丹成后诸量持续失守 | 丹意消解，复归散气（渐进，无专门事件） |

### 5.2 时间维度与滞回

每个感知档沿用既有纪律：进出双阈值（滞回），杜绝阈值附近抖动；
趋势与时长必附（「日渐沉静」与「沉静」是两个感知）。「结丹之兆」
「丹成」为一次性叙事事件（与「触碰筑基门槛」「筑基功成」同形态），
其余为连续感知档。

### 5.3 知识层命名与信息边界

- 「金丹」「结丹」是文明命名：由叙事层在事件发生时给出，与筑基
  先例一致；引擎核零专名。
- 结丹处只在已被修行者识别的穴位上显名（穴位显隐阶梯照常约束）；
  未识之处的凝聚，感知上只是「似有一处沉实，未明其所」。
- 不渲染任何「金丹进度」：判据不进界面、不进观察，连续结果原则
  在玩家侧的表达是——你只能通过感知与实验逼近「它成了没有」。
- 理解层（分身）的职责从感知开始：假设（「那团凝意或已能自持？」）、
  实验（「今夜止念，明晨验之」）、下一步意图——感知隔离律不变。

## 6. 原语与规则准入

### 6.1 不新增什么（宪法 §7 逐条过审）

| 候选 | 裁决 | 理由 |
|---|---|---|
| 旧稿能量核心存储结构（质量／密度／相干／自保持等字段） | 不引入 | 五量全部可由既有导出量重算（负载比、炼化度、构成占比与漂移、安养窗比值、稳定度）；落存储违炼化导出原则（D2 精神）；准入条件之「现有规则无法表达」「不可再拆」均不满足 |
| 相干性新字段 | 不引入 | 构成收敛由炼化导出量表达，波动受控由既有失稳计量表达；相干＝纯与稳的组合语义，拆得开就不立新 |
| 自持测量新通道 | 不引入 | 借既有松手测量协议形态，安养自然发生；评估器不写入任何世界状态 |
| 结丹意图／结丹动作 | 不引入 | 反向因果禁令（评审稿明令清单）：凝聚处由训练沉淀，策略由轨道与节律承载（§4）；「点一下结丹」是把结构相变降级为按钮 |

### 6.2 需要什么

**零新底层原语、零新算子、零守恒扩项。** 所需全部在判读层与感知层：

1. 凝实观察器（判读层，筑基观察器之间构形态）：滚动消费每拍真值，
   重算五量，产出触碰／成立／反散的判定信号；只读。
2. 感知映射条目（§5.1 表）接入既有流水线；滞回档 [v0.1 参数]。
3. 叙事词两条（结丹之兆／丹成）入叙事层。

工程锚点与判定口径版本见附录；判定语义不影响底层重演，
规则版本不动（筑基判定口径之先例）。

### 6.3 境界审核五问（境界文档 §6.3）

1. **引擎中新增了什么实体或结构？** 无新实体：既有状态的新稳定相位
   ——一处满足五量的凝实之库。
2. **它为什么不能在上一境界长期存在？** 自主循环未立时，筛选随意识
   起止，没有长期经济学；循环立而时日未足时，构成未收敛、库存未聚，
   五量不齐。
3. **形成条件能否由现有底层规则自然推导？** 能——本文因果链每一步

   边界交换的势差与基线口径、被动环流份额。
4. **能否通过数值状态与稳定性测试被确定性检测？** 五量皆导出、
   皆可检测；持续性与波动计量承袭既有机械。
5. **去掉境界名称，该结构是否仍有物理意义？** 是——高炼化质量在
   汇点的凝聚与自持，与名称无关。
