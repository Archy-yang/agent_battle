## 2. 工作包

### WP-M2-1 洞府前端改版（Vue 端重构）
- 依据：docs/design/yiqi-dongfu-redesign.html（单页叙事流：身体场景 + 感知流 +
  心念卡 + 传念 + 知识台账 + 筑基迹象），废弃五屏底导航
- 硬约束：
  - 感知流对话式正序（历史在上、最新吸底、贴底自动跟随），折起/展开
  - 玩家侧零数字、零机器词（LLM/模型/Runtime/seed/tick 不渲染）；后端给的
    band 数仅作色档，不显示数值
  - 穴位显隐阶梯：无 → 模糊波动（感知暗示后）→ 暂记名 → 稳定识别；未探明
    数量保密；经脉线只随气行事件显形（flow 动画 + 余辉），无静态线
  - 组序 = 单向环语义：点选欲经之穴，气按环向经过，末归丹田；途经未识之穴
    接触显形
  - go:embed：改完必须 `go build -o worldd ./cmd/worldd` 重启生效
- 验收：手机视口（390×844）截图全流程走查；`npm run build` 通过；与
  ScriptedPilot 会话端到端可玩

## 5. 风险

- R1 感知流正序与"回执置顶"的交互：回执是高价值信息，正序下可能被淹没
  → 折起态只露最新，重要事件（请示/异变）考虑高亮而非置顶
- R2 单页叙事流信息密度：知识台账常驻会挤压感知流 → 展开态限高已定，观察
  用户反馈
- R3 分身提示词随语义膨胀：主环/逆流/炼化三段表象已加，继续加会稀释 →
  WP-M2-2 时重排提示词结构
