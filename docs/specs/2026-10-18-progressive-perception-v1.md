## 0. 体感次第（设计本源）

一般修真体感：入静内视若暗 → 某处气感如丝 → 有感处反复气至、渐辨其形 →
得其名 → 气行沿路线而走、走过方知有路 → 多走成熟路。对应揭示阶梯：

```text
穴位：无感 → 隐约 → 有感而未知 → 显名 → 详察
经脉：无迹 → 初显（淡虚线） → 熟路（实线）
```

## 1. 感知层私有状态：熟识度

感知层在 w.sensory 中为每穴、每经脉段维护**熟识度**（定点整数、私有、
确定性、随 seed 重放一致；先例：percept.go 滞回记忆）。

- **穴位熟识度**：该穴气机活跃（非停滞或有压感信号）的每一息 +1；
  静观/被观察不直接给分（看一眼不会熟，气到了才算数）。
- **凝神细察加速**（复用既有 inspect 意图，不新增原语）：对该穴凝神一次
  熟识度 +3（初值，批测可调）。凝神无感之穴 → 回执"无从察起"。
- **经脉熟识度**：该段有气行（flow 事件经过）的每一息 +1。

## 2. 阈值阶梯（初值，cultmc 批测可调）

| 对象 | 档 | 阈值 | 玩家所见 |
| --- | --- | --- | --- |
| 穴位 | 无感 | 0 | 不渲染 |
| 穴位 | 隐约 | ≥1 | 波动稍亮的虚淡圈，无名 |
| 穴位 | 有感 | ≥3 | 实感小圆点，**无名**，点开只见感受词 |
| 穴位 | 显名 | ≥6 | 得暂记名，浮卡渐全（开度/气带等） |
| 经脉 | 无迹 | 0 | 不渲染 |
| 经脉 | 初显 | ≥1 | 淡虚线（两端皆显名才画，下同） |
| 经脉 | 熟路 | ≥4 | 实线 |

档位词（无感/隐约/有感/显名；无迹/初显/熟路）进 Observation 定性字段。
熟识度数值本身绝不外泄（感知隔离律）。

## 3. 显名节奏预算

**每息至多一穴新越「显名」阈**，取当息气机最活跃者；并列取先。
越「隐约」「有感」阈不设预算。此预算保证满屏齐出在引擎层即不可能。

## 4. 未显名的指称：方位语

未显名之穴在感知流与观察中以**方位语**指称，不落名、不落数。
方位语是地形描述（身体图上位置本就可见），不泄身份：

| 穴 | 方位语 |
| --- | --- |
| 神庭 | 额上 |
| 青关 | 左胁 |
| 阳枢 | 右胁 |
| 中庭 | 胸口 |
| 玄泉 | 左腹 |
| 金门 | 右腹 |
| 土府 | 脐旁 |
| 下丹田 | 脐下 |

Observation.Points 增加定性档位字段；未至显名者 Name 置空、由
 senseLine 以方位语行文（如"脐下隐有微动，气机没有动静"）。
 **零泄名机检**：序列化全文断言——档位低于显名的穴，其名不得出现在
 任何观察/感知流文本中。

## 5. 前端（行动台改版之上叠加）

- 穴位渲染按档：无感不渲染；隐约=虚淡圈微亮化；有感=实感 node 无字；
  显名=得名字。退役现"有实感即显名"的 knownPoints 启发式（引擎给档）。
- 点未显名处（隐约/有感）→ 浮卡：感受词 + **凝神细察**按钮（inspect）。
- 点已显名处 → 详情浮卡 + **自此引气**按钮（absorb 任意穴，自由选择；
  心念卡建议保留作快捷入口）。身体图升级为主操作面。
- 经脉按档：初显=淡虚线（行气时流动动画照旧），熟路=实线。
- 感知条/心声文案经白话转写层照旧；档位词如需口语化在转写层做。
