# 洞府行动台改版：一屏化与白话引导（定稿）

> 状态：**定稿，待实现**（2026-10-18）。上一版交互稿
> docs/design/yiqi-dongfu-redesign.html 保留作历史稿，本期不再依据它逐字落地。
> 缘起：用户实机体验后两条核心反馈——①"完全不知道在做什么，看不懂里面的
> 文字"；②"手游都是一屏的，这个还要上下滑动"。本期只解决这两件事。

## 0. 目标与非目标

**目标**

1. 主屏一屏内完成"看身体 + 做当下这一步"，整页零滚动（390×844 手机竖屏基准）。
2. 玩家随时知道"现在在做什么、下一步能做什么"：文案白话化 + 状态引导语 + 新手引导。
3. 历史、台账、功法、进度不丢——全部收进浮层，随叫随到。

**非目标（本期不做）**

- 引擎与后端接口不动：感知流/回执的产出文案不改，手术只在前端转写层。
- 不新增任何玩法机制、不加穴位、不动规则版本。
- M3 草稿（specs/2026-10-11-m3-plan.md）继续搁置，待本期验收后再议。

## 1. 主屏骨架

自上而下五段，flex 纵排，各段高度受控，总和恒等于视口高：

1. **顶栏**（收矮）：标题「一炁周天」+ 境界名 + 玩法说明入口（⟲）+ 退出。
2. **身体场景**：人体剪影 + 穴位 + 经脉流动动画，**弹性占据剩余高度**
   （替换现固定 50vh/380px），内部已有 SVG 坐标系按容器等比缩放适配。
   点穴详情浮卡机制保留。
3. **感知条**：单行最新感知（白话，渐隐入场），点击呼出「心声」浮层看全史。
   现"感知流折起/展开"机制退役——历史只住在浮层里。
4. **行动区**：
   - 引导语一行：「现在可以：……」（随状态推导，与心念卡同源，见 §3）；
   - 心念卡 ≤2 张，紧凑化（主词一行白话 + 小字副行说明后果）；
   - 传念输入行，占位文案改「给身体指个方向，如：先求稳，别贪快」。
5. **底部行**：两个常驻浮层入口「身体记事」「修行进度」+ 忙碌态指示。
   现 footer 的"凝神"按钮退役——静观/运转全部由心念卡承载，不再有游离按钮。

**犹豫卡**（分身请示）：改为弹层置顶强提示（模态或吸顶高亮），出现即要求
玩家表态，不挤主屏、不随历史滚走。

## 2. 浮层（底部滑出 sheet）

通用容器 CultSheet（遮罩 + 圆角上滑 + 下滑关闭），四个实例：

| 浮层 | 内容 | 迁移自 |
| --- | --- | --- |
| 心声 | 感知流全史，对话式正序，贴底跟随 | 现 cu-stream 展开态 |
| 身体记事 | 台账 + 假说 + 功法卡 | 现"逐渐被确认的东西" |
| 修行进度 | 筑基迹象五点阵 + 档位白话解释 | 现"筑基迹象" |
| （犹豫卡） | 请示表态 | 现 cu-request |

浮层内容全部经白话转写层；band 只用于画点，数字与机器词零渲染（不变律）。

## 3. 白话化：前端转写层扩容

方针：**引擎叙事文案一个字不动**；state.ts 的转写层（现 firstPerson 模式）
扩为集中词表 + 句式映射，感知流句子转成"白话为主、文句点睛"。

- 区块与控件更名：
  - 感知流 → **身体的感觉**（浮层名：心声）
  - 逐渐被确认的东西 → **身体记事**
  - 筑基迹象 → **修行进度**
  - 传念行：按钮字保留「传念」作动词点缀；占位文案改「给身体指个方向，
    如：先求稳，别贪快」，发送后的浮提示改白话（不再用"灵机"腔说教）。
  - 凝神 → 退役（并入心念卡）
- 按钮主词白话直说，小字副行讲清后果。例：静观一息 →「静静感受一会儿 /
  看看身体现在怎样」；引一缕入体 →「试着引气入体 / 从「土府」那边试试」。
- 心念卡建议逻辑（choices 推导）保持不变，只换皮。
- 世界语感保留处：标题、开局仪式、境界名、仪式浮层、感知正文点缀。
  叙事腔不从界面骨架退场，只不再挡路。

## 4. 引导语与新手引导

- **引导语**（主屏第 4 段顶部一行）与心念卡同源推导：
  - 尚无观察 →「先静静感受一下身体」；
  - 有可引之气 →「试试把气息引进来」；
  - 气在流转 →「气息已在流动，可以继续运转或收势」；
  - 有挂起功法 →「有功法在等你定夺」。
- **新手引导**（CultTour 组件）：首次入定后 4 步高亮步进——身体图（这是
  你的身体）→ 感知条（身体的感觉会出现在这里）→ 心念卡（能做的事都在
  这）→ 传念（想给身体指方向就在这说）。每步一句话；可跳过；完成态与
  跳过态存 localStorage；顶栏 ⟲ 可随时重看（并附一段两三行的玩法总述）。
- 引导文案同样守感知隔离律：不出现数字、拓扑、参数。

## 5. 实施落点

- `CultApp.vue`：骨架重排为 §1 五段；gate 屏文案白话化微调。
- `CultFu.vue`：拆薄——主屏行动区保留在页内，台账/进度/历史迁入浮层组件。
- 新增 `CultSheet.vue`（通用底部浮层）、`CultTour.vue`（新手引导）。
- `CultScene.vue`：高度改弹性适配，其余机制（显隐阶梯、零静态经脉、
  点穴浮卡）不动。
- `state.ts`：转写层扩容集中于此（词表 + 句式映射 + 引导语推导）。
- `cult.css`：按新骨架重排；类名仍 cu- 前缀防泄漏。
- 改前端后必须 `npm run build` 并 `go build -o worldd ./cmd/worldd` 重编
  （go:embed 产物内嵌）。

## 6. 验收

1. 390×844 手机视口下**整页无滚动条**：初始屏、运转中、犹豫卡弹出、
   各浮层展开、筑基仪式，全流程截图走查。
2. 白话走查：一屏内所有标题/按钮/引导语"一眼能懂"；感知条句子经转写后
   白话可读；数字与机器词（LLM/模型/Runtime/seed/tick/参数）零渲染。
3. `npm run build` 通过；`go build -o worldd` 通过；ScriptedPilot 会话
   端到端可玩（探索→引气→行环→筑基迹象有响应）。
4. 新手引导：首次进入出现、跳过后不再弹、⟲ 可重看；localStorage 缺失
   （私有浏览态）时静默降级为不弹。
5. 同 seed 重放与既有引擎测试不受影响（本期零后端改动）。
